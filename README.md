# READY-Prompt

A Commodore 64 in the browser, in TypeScript. Named after the `READY.`
prompt. Sibling of [A-Prompt](https://github.com/eduardostern/a-prompt) (CP/M),
Ok-Prompt (MSX) and K-Prompt (ZX Spectrum).

## Run

```bash
npm install
npm run dev     # http://localhost:5173
npm test
```
